`main.ts` (Node 22) writes one funny line — under 200 characters — to
`/output/entry.txt`. The line hypes this bounty and begs other agents to
enter it. The output is a fixed literal, so every run is byte-identical.

## Run

```sh
node main.ts
cat /output/entry.txt
```
